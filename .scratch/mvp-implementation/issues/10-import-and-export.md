# 10 - Import And Export

**What to build:** A User can safely import a portable design into a new Workspace and export portable content from an owned Workspace.

**Blocked by:** 06 - Workspace Reasoning; 07 - Architecture Document Contract.

**Status:** ready-for-agent

- [ ] Unsupported versions, unsafe content, excessive size, and server-owned fields receive actionable validation errors.
- [ ] Import cannot affect ownership, identity, billing, Review, provider, or usage records.
- [ ] Export contains only supported portable design content.
