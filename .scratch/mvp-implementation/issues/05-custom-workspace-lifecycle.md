# 05 - Custom Workspace Lifecycle

**What to build:** A Free User can create and manage owned Custom Workspaces from a dashboard without receiving an AI-generated architecture.

**Blocked by:** 03 - Free Plan And Usage Policy.

**Status:** completed

- [x] A User can create, list, rename, archive, restore, and permanently delete owned Workspaces.
- [x] Active-Workspace Entitlements and ownership are enforced by the backend.
- [x] The dashboard communicates source, progress, and save state for each Workspace.

## Approved UI alignment

Implement the approved Practice Home, Custom Design entry, Workspace cards, account menu, archive, and deletion-confirmation patterns on desktop and mobile. A Custom Workspace begins with only a name and System Idea, never an AI-generated architecture. Workspace cards make source, progress, save state, resume action, and destructive actions clear; archive and permanent deletion require explicit confirmation and accessible recovery/error feedback.

The detailed Custom Design practice flow remains governed by tickets 06, 07, 08, 19, and 20.
