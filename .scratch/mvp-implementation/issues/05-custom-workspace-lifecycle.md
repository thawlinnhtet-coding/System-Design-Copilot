# 05 - Custom Workspace Lifecycle

**What to build:** A Free User can create and manage owned Custom Workspaces from a dashboard without receiving an AI-generated architecture.

**Blocked by:** 03 - Free Plan And Usage Policy.

**Status:** ready-for-agent

- [ ] A User can create, list, rename, archive, restore, and permanently delete owned Workspaces.
- [ ] Active-Workspace Entitlements and ownership are enforced by the backend.
- [ ] The dashboard communicates source, progress, and save state for each Workspace.
