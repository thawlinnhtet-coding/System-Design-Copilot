# 09 - Curated Challenge Catalog

**What to build:** Users can browse product-maintained Curated Challenges and start private Workspaces from URL shortener, news feed, and ticket-booking prompts.

**Blocked by:** 03 - Free Plan And Usage Policy; 05 - Custom Workspace Lifecycle; 07 - Architecture Document Contract.

**Status:** ready-for-agent

- [ ] The product seeds URL shortener, news feed, and ticket-booking Challenges without a Challenge-authoring UI.
- [ ] Challenge visibility is enforced by backend Entitlements.
- [ ] Starting a Challenge creates a private Workspace and never changes the source Challenge.
